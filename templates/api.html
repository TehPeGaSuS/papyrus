Posting from scripts

Pastes are plain text. No account or key is needed; the address below is this site. Every example prints a Paste URL, a Raw URL and a Removal URL (keep that one private: opening it removes the paste).

From the shell

Pipe anything in (post to the address itself; curl needs no -X POST with -F):

{{ code('$ echo "your text" | curl -F \'file=@-\' ' ~ base ~ '/\nPaste URL: ' ~ base ~ '/3f9c1a7e2b4d\nRaw URL: ' ~ base ~ '/raw/3f9c1a7e2b4d\nRemoval URL: ' ~ base ~ '/remove/…') }}

Send a file. Its name is kept, and its extension picks the syntax highlighting:

{{ code("$ curl -F 'file=@deploy.sh' " ~ base ~ "/") }}

Add a description, an expiry and comments. Name piped text with ;filename=:

{{ code("$ curl -F 'file=@deploy.sh' -F title='Deploy helper' -F expires_in=" ~ example_expiry ~ " -F comments=1 " ~ base ~ "/\n$ echo '# Notes' | curl -F 'file=@-;filename=notes.md' " ~ base ~ "/") }}

Form fields

FieldMeaning
filea file upload (-F 'file=@name', or @- for standard input); repeat it for more files. The name is kept and its extension picks the language; piped text takes a name with ;filename=. UTF-8 text only
titleoptional description
languageoptional (repeat it, in order, for several files); auto or omitted means "from the filename". Names: /api/languages
expires_inoptional, one of the values below (default {{ default_expiry }})
commentsoptional, 1 lets visitors comment, 0 doesn't; left out, the site's default applies (and a site can turn comments off entirely)

Several files in one paste

Repeat file for each file, up to {{ max_files }} files. The reply has one raw URL per file.

{{ code("$ curl -F 'file=@main.py' -F 'file=@README.md' " ~ base ~ "/\nPaste URL: " ~ base ~ "/3f9c1a7e2b4d\nRaw URL (main.py): " ~ base ~ "/raw/3f9c1a7e2b4d\nRaw URL (README.md): " ~ base ~ "/raw/3f9c1a7e2b4d/README.md\nRemoval URL: " ~ base ~ "/remove/…") }}

JSON

POST /create with Content-Type: application/json. One file:

{{ code('{"content": "print(1)\\n", "filename": "hello.py", "title": "Hello", "expires_in": "' ~ example_expiry ~ '", "comments": false}') }}

Several files:

{{ code('{"title": "Project", "files": [\n {"filename": "main.py", "content": "print(1)\\n"},\n {"filename": "README.md", "content": "# Hi"}\n]}') }}

The answer is JSON; url and removal_url are paths on this site:

{{ code('{"paste_id": "3f9c1a7e2b4d", "url": "/3f9c1a7e2b4d", "removal_token": "…", "removal_url": "/remove/…"}') }} {{ code("$ curl -s -X POST " ~ base ~ "/create -H 'Content-Type: application/json' \\\n -d '{\"content\": \"hello\", \"filename\": \"hi.txt\"}'") }}

Reading and removing

GET /<id>the page (?view=preview shows Markdown files rendered, ?f=2&L=5-12 highlights lines of the second file)
GET /raw/<id>the first file as text/plain
GET /raw/<id>/<filename>any file of the paste
GET or POST /remove/<token>removes the paste at once, no confirmation, so plain curl works (a HEAD request only checks)
{{ code("$ curl " ~ base ~ "/raw/3f9c1a7e2b4d\n$ curl " ~ base ~ "/remove/ # the Removal URL: fetching it removes the paste (POST works too)") }}

Limits

  • UTF-8 text only (binary is refused with 415); at most {{ max_size }} per paste in total and {{ max_files }} files.
  • 10 pastes per 10 minutes per address.
